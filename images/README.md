# Image Assets Guide

All images used by `index.html` are stored locally in this directory (`c:/Users/PC/PROJECTS/first/images/`). You can replace, edit, or swap any file here directly, and the website will immediately reflect the changes.

## How to Edit or Replace
1. Overwrite any of the files above with your preferred `.jpg` or `.png` file using the same filename.
2. If you add a new image name, simply update the `src="images/your-new-name.jpg"` in [`index.html`](../index.html).
